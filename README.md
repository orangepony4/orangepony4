# orangepony4

Open-source tools for hands-free control, chat analysis and game development.

[Читать по-русски ↓](#русская-версия)

![An activity chart and a webcam pointer diagram](assets/project-index.svg)

## Featured projects

### Telegram Analyzer

**Browser app · Offline ZIP**

Try the built-in chat or open a Telegram Desktop JSON file. Filter an account export by name and chat type. The chooser shows the full chat name and message count. Read message types in a table and export their counts, activity, reply times, or reactions as CSV. Files stay in your browser.

[![Try it here — Telegram Analyzer](assets/try-en.svg)](https://orangepony4.github.io/telegram-analyzer/)

[Analyze my export](https://orangepony4.github.io/telegram-analyzer/?view=upload) · [Source & guide](https://github.com/orangepony4/telegram-analyzer) · [Offline ZIP](https://github.com/orangepony4/telegram-analyzer/releases/latest)

### Nose Pointer

**Windows · Webcam**

Move the pointer with your nose. Wink or hold the pointer still to click. On Windows 10 or 11 (x64), extract the ZIP and run **Start Nose Pointer.cmd**. The first setup needs internet. Nose Pointer remembers the camera number after practice calibration. Press **F8** to pause.

[![Download for Windows — Nose Pointer](assets/windows-en.svg)](https://github.com/orangepony4/nose-pointer/archive/refs/tags/v0.10.2.zip)

[Setup guide](https://github.com/orangepony4/nose-pointer#install-on-windows) · [Check setup with camera off](https://github.com/orangepony4/nose-pointer#privacy-and-testing) · [Release notes](https://github.com/orangepony4/nose-pointer/releases)

## More tools

### Palette Contrast

Check text contrast against WCAG 2.2 and compare every pair in a UI palette. Save or share the palette in a link. Switch between English and Russian in the header.

[![Try it here — Palette Contrast](assets/try-en.svg)](https://orangepony4.github.io/palette-contrast/)

[Source](https://github.com/orangepony4/palette-contrast) · [Offline ZIP](https://github.com/orangepony4/palette-contrast/releases/latest)

### Sprite Grid Inspector

Lay a grid over a PNG sprite sheet, find empty cells and export transparent frames individually or together in a ZIP. Switch between English and Russian in the header.

[![Try it here — Sprite Grid Inspector](assets/try-en.svg)](https://orangepony4.github.io/sprite-grid-inspector/)

[Source](https://github.com/orangepony4/sprite-grid-inspector) · [Offline ZIP](https://github.com/orangepony4/sprite-grid-inspector/releases/latest)

- **[Archive Check](https://github.com/orangepony4/archive-check)** builds SHA-256 manifests and flags missing, changed or extra files after a copy or restore. [Release](https://github.com/orangepony4/archive-check/releases/latest)
- **[Texture Budget](https://github.com/orangepony4/texture-budget)** estimates texture memory for PNG, JPEG and WebP assets, including mipmaps. [Release](https://github.com/orangepony4/texture-budget/releases/latest)

### Основные проекты

#### Telegram Analyzer

**Браузер · Офлайн-архив**

Откройте демо-чат или загрузите JSON из Telegram Desktop. В экспорте аккаунта можно искать по названию и типу чата. Полное название и число сообщений видны до запуска анализа. Смотрите типы сообщений в таблице и выгружайте число записей по типам, активность, время ответов или количество реакций в CSV. Файлы обрабатываются в браузере.

[![Попробовать здесь — Telegram Analyzer](assets/try-ru.svg)](https://orangepony4.github.io/telegram-analyzer/)

[Разобрать свой экспорт](https://orangepony4.github.io/telegram-analyzer/?view=upload) · [Код и инструкция](https://github.com/orangepony4/telegram-analyzer) · [Офлайн-архив](https://github.com/orangepony4/telegram-analyzer/releases/latest)

#### Nose Pointer

**Windows · Веб-камера**

Двигайте указатель носом, щёлкайте подмигиванием или задержкой на цели. В Windows 10 или 11 (x64) распакуйте ZIP и запустите **Start Nose Pointer.cmd**. Для первой установки нужен интернет. После калибровки в режиме пробы Nose Pointer запоминает номер камеры. **F8** ставит управление на паузу.

[![Скачать для Windows — Nose Pointer](assets/windows-ru.svg)](https://github.com/orangepony4/nose-pointer/archive/refs/tags/v0.10.2.zip)

[Инструкция по запуску](https://github.com/orangepony4/nose-pointer#запуск-на-windows) · [Проверить установку без камеры](https://github.com/orangepony4/nose-pointer#приватность-и-проверки) · [Заметки к релизам](https://github.com/orangepony4/nose-pointer/releases)

### Другие инструменты

#### Palette Contrast

Проверяет контраст текста по WCAG 2.2 и сравнивает все пары цветов в палитре интерфейса. Палитру можно сохранить в ссылке. Выберите английский или русский в шапке.

[![Попробовать здесь — Palette Contrast](assets/try-ru.svg)](https://orangepony4.github.io/palette-contrast/)

[Код](https://github.com/orangepony4/palette-contrast) · [Офлайн-архив](https://github.com/orangepony4/palette-contrast/releases/latest)

#### Sprite Grid Inspector

Накладывает сетку на PNG-лист спрайтов, находит пустые ячейки и сохраняет кадры с прозрачностью по отдельности или одним ZIP. Выберите английский или русский в шапке.

[![Попробовать здесь — Sprite Grid Inspector](assets/try-ru.svg)](https://orangepony4.github.io/sprite-grid-inspector/)

[Код](https://github.com/orangepony4/sprite-grid-inspector) · [Офлайн-архив](https://github.com/orangepony4/sprite-grid-inspector/releases/latest)

- **[Archive Check](https://github.com/orangepony4/archive-check)** создаёт SHA-256 манифесты и находит пропавшие, изменённые и лишние файлы после копирования или восстановления. [Релиз](https://github.com/orangepony4/archive-check/releases/latest)
- **[Texture Budget](https://github.com/orangepony4/texture-budget)** оценивает расход памяти текстурами PNG, JPEG и WebP с учётом мипмапов. [Релиз](https://github.com/orangepony4/texture-budget/releases/latest)
