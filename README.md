# orangepony4

Open-source tools for hands-free control, chat analysis and game development.

[Читать по-русски ↓](#русская-версия)

![An activity chart and a webcam pointer diagram](assets/project-index.svg)

## Featured projects

### Telegram Analyzer

**Browser app · Offline ZIP**

[![Try it here — Telegram Analyzer](assets/try-en.svg)](https://orangepony4.github.io/telegram-analyzer/)

Try the sample chat or open a Telegram Desktop JSON export. Find participants by name and save the visible rows as CSV. Download activity by weekday and hour, print the report, or save charts as PNG. Files stay in your browser.

[Analyze my export](https://orangepony4.github.io/telegram-analyzer/?view=upload) · [Source & guide](https://github.com/orangepony4/telegram-analyzer) · [Offline ZIP](https://github.com/orangepony4/telegram-analyzer/releases/latest)

### Nose Pointer

**Windows · Webcam**

[![Download for Windows — Nose Pointer](assets/windows-en.svg)](https://github.com/orangepony4/nose-pointer/archive/refs/tags/v0.12.7.zip)

Move the pointer with your nose. Wink or hold the pointer still to click. In practice mode, choose mirrored or direct movement under **Horizontal movement**. On Windows 10 or 11 (x64), extract the ZIP and run **Start Nose Pointer.cmd**. The first setup needs internet. Press **F8** to pause.

[Setup guide](https://github.com/orangepony4/nose-pointer#install-on-windows) · [Dwell with one eye](https://github.com/orangepony4/nose-pointer#dwell-with-one-eye-open) · [Check setup with camera off](https://github.com/orangepony4/nose-pointer#privacy-and-testing) · [Release notes](https://github.com/orangepony4/nose-pointer/releases)

## More tools

### Palette Contrast

Check text contrast against WCAG 2.2 and compare every pair in a UI palette. The text colors stay visible as you scroll the matrix. Save or share the palette in a link.

[![Try it here — Palette Contrast](assets/try-en.svg)](https://orangepony4.github.io/palette-contrast/)

[Source](https://github.com/orangepony4/palette-contrast) · [Offline ZIP](https://github.com/orangepony4/palette-contrast/releases/latest)

### Sprite Grid Inspector

Lay a grid over a PNG sprite sheet, including narrow strips, and find empty cells. Export transparent frames individually or in a ZIP. You can cancel a ZIP export while it is being prepared. Switch between English and Russian in the header.

[![Try it here — Sprite Grid Inspector](assets/try-en.svg)](https://orangepony4.github.io/sprite-grid-inspector/)

[Source](https://github.com/orangepony4/sprite-grid-inspector) · [Offline ZIP](https://github.com/orangepony4/sprite-grid-inspector/releases/latest)

- **[Archive Check](https://github.com/orangepony4/archive-check)** builds SHA-256 manifests, verifies copies, and exports checksums for a selected folder. [Release](https://github.com/orangepony4/archive-check/releases/latest)
- **[Texture Budget](https://github.com/orangepony4/texture-budget)** estimates texture memory for PNG, JPEG and WebP assets, including mipmaps. [Release](https://github.com/orangepony4/texture-budget/releases/latest)

### Основные проекты

#### Telegram Analyzer

**Браузер · Офлайн-архив**

[![Попробовать здесь — Telegram Analyzer](assets/try-ru.svg)](https://orangepony4.github.io/telegram-analyzer/)

Откройте демо-чат или загрузите JSON из Telegram Desktop. Ищите участников по имени и сохраняйте видимые строки в CSV. Выгружайте активность по дням недели и часам, печатайте отчёт или сохраняйте графики в PNG. Файлы обрабатываются в браузере.

[Разобрать свой экспорт](https://orangepony4.github.io/telegram-analyzer/?view=upload) · [Код и инструкция](https://github.com/orangepony4/telegram-analyzer) · [Офлайн-архив](https://github.com/orangepony4/telegram-analyzer/releases/latest)

#### Nose Pointer

**Windows · Веб-камера**

[![Скачать для Windows — Nose Pointer](assets/windows-ru.svg)](https://github.com/orangepony4/nose-pointer/archive/refs/tags/v0.12.7.zip)

Двигайте указатель носом, щёлкайте подмигиванием или задержкой на цели. В режиме пробы выберите зеркальное или прямое движение в настройке **«По горизонтали»**. В Windows 10 или 11 (x64) распакуйте ZIP и запустите **Start Nose Pointer.cmd**. Для первой установки нужен интернет. **F8** ставит управление на паузу.

[Инструкция по запуску](https://github.com/orangepony4/nose-pointer#запуск-на-windows) · [Задержка с одним глазом](https://github.com/orangepony4/nose-pointer#задержка-с-одним-открытым-глазом) · [Проверить установку без камеры](https://github.com/orangepony4/nose-pointer#приватность-и-проверки) · [Заметки к релизам](https://github.com/orangepony4/nose-pointer/releases)

### Другие инструменты

#### Palette Contrast

Проверяет контраст текста по WCAG 2.2 и сравнивает все пары цветов в палитре интерфейса. При прокрутке матрицы цвета текста остаются видимыми. Палитру можно сохранить в ссылке.

[![Попробовать здесь — Palette Contrast](assets/try-ru.svg)](https://orangepony4.github.io/palette-contrast/)

[Код](https://github.com/orangepony4/palette-contrast) · [Офлайн-архив](https://github.com/orangepony4/palette-contrast/releases/latest)

#### Sprite Grid Inspector

Накладывает сетку на PNG-лист спрайтов, в том числе на узкие полосы, и находит пустые ячейки. Сохраняет кадры с прозрачностью по отдельности или одним ZIP. Подготовку ZIP можно отменить. Выберите английский или русский в шапке.

[![Попробовать здесь — Sprite Grid Inspector](assets/try-ru.svg)](https://orangepony4.github.io/sprite-grid-inspector/)

[Код](https://github.com/orangepony4/sprite-grid-inspector) · [Офлайн-архив](https://github.com/orangepony4/sprite-grid-inspector/releases/latest)

- **[Archive Check](https://github.com/orangepony4/archive-check)** создаёт манифесты SHA-256, проверяет копии и выгружает контрольные суммы выбранной папки. [Релиз](https://github.com/orangepony4/archive-check/releases/latest)
- **[Texture Budget](https://github.com/orangepony4/texture-budget)** оценивает расход памяти текстурами PNG, JPEG и WebP с учётом мипмапов. [Релиз](https://github.com/orangepony4/texture-budget/releases/latest)
