# orangepony4

Инструменты для анализа данных и повседневных задач.

### Проекты

**[Telegram Analyzer](https://github.com/orangepony4/telegram-analyzer)** · JavaScript  
Анализирует JSON-экспорт переписки Telegram. Показывает активность по времени, статистику участников и интервалы между ответами. Обработка файла происходит в браузере.

---

В каждом проекте — инструкция запуска и примеры использования по мере готовности. Вопросы и предложения можно оставить в Issues соответствующего репозитория.
